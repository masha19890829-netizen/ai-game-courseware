TOOLS · 做游戏怎么选

四类工具，各自的优势

没有「最强工具」，只有「这一棒谁跑」。原则不变：聊创意可以随便用哪个，落地改文件必须用有文件夹权限的 Agent。

本课主线 · 桌面 Agent

Codex（OpenAI）

优势绑定本地文件夹干活：读写文件、跑命令、给证据；桌面端适合新人，任务制界面清晰
适合从零做网页 Demo、小步迭代、bug 修复（本课 Q3–Q5 全部用它）
短板需要获准账号与额度；长链路大改动要拆任务喂
官方快速入门(中文)官方初学者讲座
终端强者 · 长任务

Claude Code（Anthropic）

优势长上下文 + 强规划，适合复杂规则与多文件项目；先写 spec 再动手的习惯好
适合已有工程基础的同事；Vibe Jam 2026 冠军作品几乎全由它完成（见案例墙）
短板终端界面，对纯新人不如桌面端直观
官方能力说明官方最佳实践(视频)
编辑器一体 · 创作者最多

Cursor

优势编辑器里直接对话改代码，上下文最顺手；独立游戏圈用的人最多
适合想边看代码边改的人；fly.pieter.com 就是用它三小时搓出来的（见案例墙）
短板本质是编辑器，完全不碰代码的人会有心理门槛
官网
聊天原型 · 头脑风暴

Grok / Gemini 等聊天模型

优势聊创意、出方案、写独立小脚本快；Grok 写过 fly.pieter.com 的服务器代码
适合立项前的点子碰撞、数值草案、规则推演
短板多数没有你的文件夹权限——聊天里的建议不等于已保存的游戏，选定规则要带回 Codex / Claude Code 落地
Grok 做游戏案例串(X)
国产 · 免费好上手

Kimi（月之暗面）

优势中文对话最顺、免费额度友好、零门槛；K2 模型代码能力进步快，长文本理解是招牌
适合新人聊创意、改话术、读长文档；把想法整理成能落地的规则
短板网页聊天没有你的文件夹权限——落地要交给 Codex / Claude Code
官网开发者平台
国产 · 开源生态

通义千问 Qwen（阿里）

优势开源模型系，Qwen3-Coder 在代码榜单位列国产前列；可私有化部署，公司内网合规友好
适合有合规/私有化要求的团队；想自建内部代码助手的工程组
短板要自己搭环境才有 Agent 能力，纯新人直接用聊天版即可
Qwen3 开源仓库
国产 · 极客性价比

DeepSeek

优势代码与推理能力强、API 价格极低、开源可自建；技术圈口碑硬
适合会接 API 的同事批量跑任务；预算敏感的原型期
短板官方聊天端无文件操作；想当 Agent 用需要配合工具壳
官网
素材类工具顺带一提：美术参考图、音效、BGM 也有 AI 工具（图像生成、音乐生成），但本课主线用「代码画图形 + WebAudio 合成音」就够了——第一版别卡在素材上。
