1. 先看两个 Demo

2D、3D 各玩两分钟。今天不复刻大游戏，只亲手做出一个能玩的最小版本。

1.1 打开两份游戏

现在做什么
  1. 依次点开 2D 像素作品和 3D 竞速作品，按画面上的提示各玩两分钟。
  2. 每玩一个只回答三句话：我按了什么键？画面发生了什么？我还想试什么？

完成后看到：不是看图：你真的操作了两个网页文件，按键让画面动了。

不一样怎么办：先点一下游戏区域再按键。旧作品在当前浏览器打不开，就换矿工第一版演示，并记下异常。

作品只能证明「这份文件能做什么」，看不出做了多久、怎么做的。

2. Vibe coding 与 Agent

先分清三个角色：模型负责听懂，工具负责操作，Agent 负责把活干完。

2.1 Vibe coding：说人话做游戏

现在做什么
  1. 对比两种说法：「做一个矿工游戏」太模糊；「方向键移动、碰矿加 10 分、30 秒结束」才能做。
  2. 生成后自己玩，再说「只把 30 秒改成 45 秒」；打开新版核对，不是听它说「完成了」就信。

完成后看到：你能把制作过程说成一串动作：发中文需求 → 它建文件 → 你打开玩 → 你提意见 → 它改文件。

不一样怎么办：不用读懂代码，但不能不看文件、不试玩。做得不对就继续提，别当成必然成功。

本课的 vibe coding = 用人话一轮一轮做小版本。不是玄学，是流程。

2.2 模型、工具、Agent 的区别

现在做什么
  1. 拿「30 改成 45」举例：模型负责听懂你的意思，文件工具负责真改文件，检查工具负责试着验证。
  2. 看它是否真的操作了文件——聊天里贴一段代码，不等于你电脑里的文件被改了。

完成后看到：一句话记住：LLM 是「脑」，工具是「手」，Agent 是把脑和手组织起来干活的「人」。

不一样怎么办：能不能读写你电脑的文件，取决于你用的软件和授权——不是开了聊天它就自动能改。

Codex 是干活的「应用」，里面用模型；应用名和模型名不是一回事。

2.3 它能做，也会做错

现在做什么
  1. 你负责说清楚玩法，并允许它使用练习文件夹。
  2. 它负责把要求变成真正的游戏文件；你打开玩，把不对的地方告诉它改。

完成后看到：最终拿到的不是一句「做好了」，而是你能找到、能双击打开的游戏文件。

不一样怎么办：AI 可能写错，也可能没法替你试玩。它说没检查的部分，你自己一定要玩一遍。

Agent = 会用工具干活的 AI。本课用的工具叫 Codex。

3. 人和 AI 分别做什么

制作人不是说「更好玩」，而是先决定试哪种玩法，再限定这轮只改什么。

3.1 谁拿主意，谁动手

现在做什么
  1. 你决定：这局要试「带着矿还要不要冒险」，并且只改计分时机这一件事。
  2. 让 AI 列实现方案和检查项；你玩完决定：保留、调整，还是砍掉。

完成后看到：你出的叫「取舍」，AI 交的叫「文件和检查说明」——谁也替代不了谁。

不一样怎么办：AI 说「这样更有策略」只是猜测。必须看到规则真的变了、观察玩家怎么选，才算数。

创新不一定是加系统：改一下得分时机，也可能产生新选择。

3.2 三种情况，三种开口方式

现在做什么
  1. 玩法没想好：让它问你问题。有目标没方案：让它给 3 个小方案，先别改文件。
  2. 方案定了：写清规则、范围和检查动作，再让它动手。点左侧看完整消息。

完成后看到：同一个聊天框，你要会说「先帮我想」和「现在开始改」两种话。

不一样怎么办：不满意先看是不是阶段搞错了：你想讨论它却开工、你要文件它只动嘴。把下一步动作补清楚。

别在你还没决定时，让 AI 替你把一整套玩法做完。

3.3 每轮结束留一份记录

现在做什么
  1. 改之前，让它对照文件先列已有规则，拿不准的标「未确认」，你再选下一项。
  2. 改完让它存一份记录：入口文件、当前规则、本轮改动、检查结果、下一步只做的一件事。

完成后看到：下次回来能找到：玩哪个文件、现在有什么、哪里没查、下一步改什么——不靠翻聊天记录。

不一样怎么办：记录也会过时。换新聊天时让它对照真实文件重新核对，别当它永远记得上一轮。

史莱姆案例：先把射击、弹射、穿透的条件一条条说清再分别做，别让 AI 自己脑补规则。

4. 工具与模型怎么选

本课统一用 Codex 桌面端。跑通一条路线，比同时装三套工具重要。

4.1 工具：找能改文件的那个

现在做什么
  1. 本课用 Codex 桌面端，在你自己的文件夹里做；公司已有获准的 Claude Code 也能按同样标准练。
  2. 用 Grok 这类聊天工具聊创意可以，但选定的规则要带回制作工具里落地。

完成后看到：你要找的是「能在指定文件夹读写文件的工具」，不是只会回答问题的模型。

不一样怎么办：公司已有获准工具就先沿用。别为上课装来路不明的软件、贴密钥、加未知中转地址。

换工具不怕：找文件、试玩、检查，这三步永远不变。

4.2 模型：用默认推荐就够

现在做什么
  1. 在输入框附近的模型 / 推理选项里，先用账号默认推荐项；第一版不需要开最高档。
  2. 能手选的话：日常小游戏优先试 5.6 Terra；复杂规则或多文件查错考虑 Sol；明确小改考虑 Luna。

完成后看到：先用一个能用的选项跑完「生成 → 打开 → 修改」，按结果决定换不换，别反复刷排行榜。

不一样怎么办：看不到这些型号就用默认项。没有额度就走获准渠道——模型再强，也救不了模糊需求和开错文件。

这是按官方定位给的起步建议，不是效果保证。以你账号实际看到的为准。

7. 第一次提修改

在同一个聊天里接着说，让它改刚才做好的文件。

7.1 发送修改消息

现在做什么
  1. 先把整个「我的矿工」复制一份放在旁边，改名「我的矿工_30秒备份」；Codex 仍关联原目录。
  2. 在原任务里发修改消息；做完后重开原目录的 index.html，或按 Ctrl + R 刷新再开一局。

完成后看到：开局显示 45 秒；人物、矿石、每块 10 分都和第一版一样。

不一样怎么办：还是 30 秒？八成打开了备份文件夹。确认地址栏是原文件夹，刷新重开再看；仍不对就把现象发给 AI。

「其他不变」要说具体：速度、位置、分值、画面、操作，一个个点出来。

8. 出错了？这样反馈

不用懂代码。把你做了什么、看到什么、应该是什么，说清楚就行。

8.1 发截图，加四句话

现在做什么
  1. 先打开左侧「教学故障样本」，只吃第一块矿；看到 +20 就用 Win + Shift + S 截图。
  2. 把截图拖进 Codex，确认出现附件缩略图，再发「操作 → 实际 → 预期 → 范围」四句话。

完成后看到：AI 能照着重现问题，也知道不能顺便改时长、地图和其他玩法。

不一样怎么办：白屏也要写清「我是怎么打开的」。有报错文字就复制一起发；复制不了就截图，不用先学调试命令。

只发「有 Bug」等于没说——它不知道你刚才干了什么。

8.2 修完照原路再玩一次

现在做什么
  1. 打开正常的 45 秒版，走同样的路线吃第一块矿，确认只加 10。
  2. 走开再走回来不重复加分；重新开始分数归零。

完成后看到：同样的操作得到正确的结果，其他功能也没坏。
