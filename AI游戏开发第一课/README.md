# 从空文件夹到第一个 AI 游戏 Demo

## 打开课件

完整复制本文件夹后，用桌面 Edge / Chrome 打开 `index.html`。不要只复制入口文件；课件图片、脚本、字体和 PPT 视频在旁边的目录中。

- 课堂：10 关 / 60 分钟，33 个步骤（29 个正课、4 个选看）。先讲 Demo、LLM / Agent、分工与工具选择，再从文件夹走到第一次修改。讲师演示无需 Codex、账号或网络。
- `体验实验室.html`：免安装动手页。从 0 到 Demo 的六步路线（含可复制话术与安装录屏）、不用账号的「下指令 → 试玩 → 验收」模拟工作台、制作人工作流（五段式 / 失败模式 / 验收原则）、魔兽风 RPG 塔防八轮实操拆解、六类场景话术库、内部真实项目案例库（Dice Defense 五版录屏、实习生作品、幻塔纪元、2D/3D 作品均可页内播放或试玩）、X / YouTube 外部范例（需联网）、创新思维练习、学员作业三档与验收四维。主页右上角「▶ 体验实验室」进入。
- `塔防实操练习单.html`：配套八轮拆解的随堂练习单。每轮先自己写指令（限时 5 分钟）再展开参考话术对答案；进度本地保存、可导出练习记录.txt；Ctrl+P 打印为纸质版（自动换成书写横线）。
- 课后自己制作：需要获准账号、网络和可用的 Codex 桌面端。离线网页不会替学员调用 AI。
- `新手操作手册.html`：全部步骤和 18 条完整消息，可按 Ctrl + P 打印；每步可返回网页中的图解与演示。
- `课后参考.html`：3 个视频、4 篇官方文章的中文导读。点击外部来源才需要联网。
- `practice/矿工练习包.zip`：4 阶段 + 故障样本 + 对应消息 + 使用说明 + 作业提交单。
- `lab.html`：原有完整 A/B 玩法实验室，可独立打开。

本轮修改前的完整备份在相邻 `_课件备份/AI游戏开发第一课_大纲优化前_20260904`；更早的“重写前”备份也保留。旧课件、第二节、原 PPT、原 AI课件.zip 均不修改。

## 讲师怎么走

| 关 | 分钟 | 实际操作 |
|---|---:|---|
| 1 | 7 | 打开原 2D / 3D 作品；用迷宫饭与小矿工说明 Demo 能验证什么、不能证明什么 |
| 2 | 8 | 中文需求如何变成文件；模型、工具与 Agent 的关系；能力和错误边界 |
| 3 | 6 | 人决定体验与范围；AI 实现与检查；三种需求表达；每轮留下文件和记录 |
| 4 | 6 | Codex 主线、已有 Claude Code 替代；工具与模型区别；按当前官方定位给起步建议 |
| 5 | 8 | 安装登录、空文件夹、项目关联、路径与权限 |
| 6 | 12 | 第一条消息 → 读输出状态 → 找 index.html → 亲自试玩；与上关合计 20 分钟 |
| 7 | 4 | 先复制备份，再只改 30→45；打开前后两版核对 |
| 8 | 4 | 故障样本 → 截图和操作经过 → 正常版重复检查；Cube 作为真实描述案例 |
| 9 | 3 | 比较即时得分 / 带回才算，讨论玩家选择；画面参考与表现反馈为选看 |
| 10 | 2 | 确认文件、复制压缩、解压复查；回顾完整路线；原作业和参考书架为选看 |

讲 60 分钟时，第九关完成第三步后直接进入第十关；第十关第三步完成即结束正课。虚线步骤为选看，可课后自查。用户本轮不要求调整作业，原有要求、消息和提交模板未改。

左右键和底部按钮逐步翻页；左侧编号、关卡地图可跳关。试玩打开时移动键不翻课件。弹层右上角关闭，游戏停止。右上有全屏、显示设置；底部有讲师备注和素材来源。较长消息、案例、参考文章在弹层内滚动，不占主画面。

## 同一个游戏的四次变化

| 文件 | 规则 | 当场查什么 |
|---|---|---|
| practice/v1/index.html | 30 秒，无危险，拾取 +10 | 矿石消失、不重复加分、0 秒停止、能重开 |
| practice/v2/index.html | 只把时间改为 45 秒 | 开局和重开都是 45，其他没变 |
| practice/v3/index.html | 增加带 ! 的巡逻危险 | 碰撞回基地，已得分保留，短暂无敌 |
| practice/v4/index.html | 背包带回才入账 | 采集不入账、回基地存分、碰撞丢背包、未带回不算分 |
| practice/fault/index.html | 刻意把一块写成 +20 | 教学故障样本，不是历史 AI 失误 |

每一份 `index.html` 都是可独立携带的单文件。方向键 / WASD / 点地面移动，P 暂停，切出自动暂停；声音默认关。第三、四版可切换基础/强化表现，规则不变。重开使用同一地图种子。课件下载按钮不会生成新版本，只下载预制文件。

## 作业交什么

从空文件夹制作自己的“收集星星”游戏，提交：

1. 30 秒第一版，能打开、计分、结束、重开。
2. 只改成 45 秒的修改版，保留原版。
3. 两条实际发送的消息，以及自己写的试玩记录。

使用 `practice/作业提交模板.txt`。检查记录可在第十关填写并下载，不会上传。选做：加一条自己的规则，说明希望改变哪种玩家选择，并记录真实差别。截止时间由讲师安排。

## 真实与示意的区别

操作图是明确标注的教学示意；课内消息是模板，不是历史 AI 回复。史莱姆对话保持“保存文本重建”标记，Cube 保持“体验不等于通关”。PPT 画面、视频不证明完整制作过程或所有功能。详见 `SOURCES.md`。

外部视频未下载，字幕、登录和地区可用性以来源为准。课件进度、设置及作业记录只存当前浏览器本地；存储被禁用时仍能使用，只是不保证刷新保留。

## 维护与验收

当前数据按 `beginner-data.js` → `reference-data.js` → `outline-data.js` 加载：基础消息与原步骤、在线书架、大纲重排。`beginner.js` 负责交互，`outline-visuals.js` 负责新增图解；样式依次是 `course.css`、`beginner.css`、`outline.css`。手册使用同一数据链。新进度键为 `arcade-outline-v3`，不读取旧章节进度。

旧 `course-data.js`、`course.js` 保留但不加载。不要修改旧课程目录的数据接口。新增五条消息是探索问题、比较方案、确认已有规则、保存制作记录、确认文件工具；均为教学模板。

维护者可运行：

```text
node scripts/build-tutorials.cjs
node scripts/build-handbook.cjs
node scripts/build-references.cjs
python scripts/build-practice.py
node tests/beginner.test.cjs
node tests/model.test.cjs
node tests/content.test.cjs
node tests/outline.test.cjs
python scripts/validate_package.py
```

普通演示不需要这些工具。验收明细及未验证项见 `QA.md`。测试浏览器限制 file://，实际交付电脑请先双击入口验一次；本轮浏览器交互检查使用本地 HTTP 预览，不把它冒称为已完成双击测试。
