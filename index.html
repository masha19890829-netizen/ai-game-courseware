PROLOGUE · 序章

这 60 分钟，具体讲什么？

全程只练三件事：说清楚要什么 → 亲自打开玩 → 检查对不对。下面是逐分钟的讲解路线，你可以提前知道自己每一刻在哪里。

00–05开场你将听到什么课程目的与路线：上完课，人人能用 AI 搓出一个能玩的 Demo；三个「别被骗」先打预防针。 05–12Q1先玩：目标长什么样直接玩矿工第一版（课件内嵌）。搞清楚 Demo 是什么、为什么 30 秒小样比十页策划案有用。 12–20Q2看懂：话怎么变成游戏你说话 → Codex 干活 → 出现文件 → 你玩 → 反馈的循环；模型/工具/Agent 一次讲清。 20–40Q3动手：20 分钟做出第一版装软件 → 建空文件夹 → 关联项目 → 发第一条需求 → 找到 index.html → 亲自检查四件事。全程给可复制话术。 40–48Q4迭代：三次修改30→45 秒、加巡逻怪、背包带回家才算分。每个版本现场可玩，体会「一次只改一件事」。 48–53Q5避坑：出错这样说故障样本（+20 分的矿）现场抓虫；反馈公式「操作→实际→预期→范围」；新人 Top3 坑。 53–58Q6作业：轮到你了「收集星星」两版 + 两条真实消息 + 试玩记录；提交模板与 SVN 路径说明。 58–60收尾一句话带走AI 负责快，你负责真。课后去实验室、练习单、教程参考继续练。
